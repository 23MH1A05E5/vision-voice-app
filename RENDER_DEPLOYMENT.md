# Render Deployment

## Settings
- Runtime: Python
- Plan: Free
- Build command: `pip install -r requirements.txt`
- Start command: `gunicorn app:app`

## Environment variables
Set `GEMINI_API_KEY` in Render. Do not commit the API key to the repository.
`FLASK_SECRET_KEY` is generated by `render.yaml`.

## Notes
The app uses local SQLite/filesystem storage. On Render Free, local filesystem data is ephemeral.
For persistent production data, use PostgreSQL and object/cloud storage later.
